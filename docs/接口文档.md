## 1. 概述

### 1.1 接口规范

- **协议**：HTTPS
- **数据格式**：JSON
- **字符编码**：UTF-8
- **请求方法**：GET、POST、PUT、DELETE
- **认证方式**：JWT Token（Bearer Token）

### 1.2 统一响应格式

#### 成功响应

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": "2025-01-01T10:00:00Z"
}
```

#### 错误响应

```json
{
  "code": 400,
  "message": "请求参数错误",
  "errors": [
    {
      "field": "username",
      "message": "用户名不能为空"
    }
  ],
  "timestamp": "2025-01-01T10:00:00Z"
}
```

### 1.3 HTTP状态码

| 状态码 | 说明 |
|--------|------|
| 200 | 请求成功 |
| 201 | 创建成功 |
| 400 | 请求参数错误 |
| 401 | 未授权，需要登录 |
| 403 | 无权限访问 |
| 404 | 资源不存在 |
| 429 | 请求过于频繁 |
| 500 | 服务器内部错误 |
| 503 | 服务不可用 |

### 1.4 错误码定义

| 错误码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | 未授权 |
| 403 | 无权限 |
| 404 | 资源不存在 |
| 500 | 服务器错误 |
| 1001 | 用户名已存在 |
| 1002 | 手机号已注册 |
| 1003 | 邮箱已注册 |
| 1004 | 用户名或密码错误 |
| 1005 | Token已过期 |
| 1006 | Token无效 |
| 2001 | 问诊记录不存在 |
| 2002 | AI服务不可用 |
| 3001 | 健康档案不存在 |
| 3002 | 数据不足，无法分析 |
| 4001 | 文章不存在 |
| 4002 | 文章已下架 |
| 5001 | 医生不存在 |
| 5002 | 排班冲突 |

## 2. 认证授权接口

### 2.1 用户注册

**接口地址**：`POST /auth/register`

**接口描述**：用户注册接口，支持手机号、邮箱注册

**请求头**：
```
Content-Type: application/json
```

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| username | string | 是 | 用户名，3-20个字符 |
| password | string | 是 | 密码，8-20个字符，包含字母和数字 |
| phone | string | 否 | 手机号，11位数字 |
| email | string | 否 | 邮箱地址 |
| verification_code | string | 否 | 验证码（手机号注册时必填） |

**请求示例**：

```json
{
  "username": "zhangsan",
  "password": "12345678",
  "phone": "13800138000",
  "email": "zhangsan@example.com"
}
```

**响应示例**：

```json
{
  "code": 201,
  "message": "注册成功",
  "data": {
    "user_id": 1,
    "username": "zhangsan",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expires_in": 3600
  },
  "timestamp": "2025-01-01T10:00:00Z"
}
```

### 2.2 用户登录

**接口地址**：`POST /auth/login`

**接口描述**：用户登录接口，支持多种登录方式

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| login_type | string | 是 | 登录类型：password/sms/third_party |
| username | string | 否 | 用户名（password登录时必填） |
| phone | string | 否 | 手机号（sms登录时必填） |
| email | string | 否 | 邮箱（password登录时可选） |
| password | string | 否 | 密码（password登录时必填） |
| verification_code | string | 否 | 验证码（sms登录时必填） |
| third_party_type | string | 否 | 第三方类型：wechat/alipay（third_party登录时必填） |
| third_party_token | string | 否 | 第三方Token（third_party登录时必填） |

**请求示例**：

```json
{
  "login_type": "password",
  "username": "zhangsan",
  "password": "12345678"
}
```

**响应示例**：

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "user_id": 1,
    "username": "zhangsan",
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "refresh_token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "expires_in": 3600,
    "refresh_expires_in": 7200
  },
  "timestamp": "2025-01-01T10:00:00Z"
}
```

### 2.3 刷新Token

**接口地址**：`POST /auth/refresh`

**接口描述**：刷新访问Token

**请求头**：
```

**响应示例**：

    "expires_in": 3600

}
```

### 2.4 发送验证码

**接口地址**：`POST /auth/send-code`

**接口描述**：发送短信验证码

**请求参数**：

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| phone | string | 是 | 手机号 |
| code_type | string | 是 | 验证码类型：register/login/reset_password |

**请求示例**：

```json
{
  "phone": "13800138000",
  "code_type": "register"
}
```

**响应示例**：

```json
{
  "code": 200,

  "data": {
    "expires_in": 300
  },
  "timestamp": "2025-01-01T10:00:00Z"

```

### 2.5 退出登录

    url = f"{BASE_URL}/consultations"
    headers = {
        "Authorization": f"Bearer {token}",
        "Content-Type": "application/json"
    }
    data = {"symptoms": symptoms} if symptoms else {}
    response = requests.post(url, json=data, headers=headers)
    return response.json()

# 发送问诊消息
def send_message(consultation_id, content, token):
    url = f"{BASE_URL}/consultations/{consultation_id}/messages"
    headers = {
        "Authorization": f"Bearer {token}",
        "Content-Type": "application/json"
    }
    data = {"content": content}
    response = requests.post(url, json=data, headers=headers)
    return response.json()

### 13.2 常见问题

#### Q1: Token过期如何处理？

**A**: Token过期后，可以使用refresh_token调用`/auth/refresh`接口刷新Token。如果refresh_token也过期，需要重新登录。

#### Q2: 如何实现分页查询？

**A**: 使用`page`和`page_size`参数，例如：
```
GET /articles?page=1&page_size=20
```

#### Q3: 文件上传大小限制是多少？

**A**: 
- 图片文件：最大5MB
- 文档文件：最大10MB
- 支持的文件类型请参考各接口说明

#### Q4: 如何处理并发请求？

**A**: 系统支持并发请求，但建议：
- 合理控制请求频率，避免触发限流（429错误）
- 对于批量操作，使用批量接口而非循环调用单个接口
- 使用异步方式处理耗时操作

#### Q5: 错误码如何解读？

**A**: 
- 2xx：成功
- 4xx：客户端错误（参数错误、权限不足等）
- 5xx：服务器错误

具体错误码请参考"1.4 错误码定义"章节。

### 13.3 接口限流说明

系统对API接口实施限流策略：

- **普通接口**：每分钟最多100次请求
- **认证接口**：每分钟最多10次请求
- **文件上传接口**：每分钟最多20次请求

超过限制将返回429状态码，建议：
1. 实现请求重试机制（指数退避）
2. 缓存频繁访问的数据
3. 使用批量接口减少请求次数

### 13.4 数据格式说明

#### 日期时间格式

所有日期时间字段使用ISO 8601格式：
- 日期：`YYYY-MM-DD`，如 `2025-01-01`
- 日期时间：`YYYY-MM-DDTHH:mm:ssZ`，如 `2025-01-01T10:00:00Z`

#### 分页响应格式

所有分页接口统一返回格式：
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "total": 100,        // 总记录数
    "page": 1,           // 当前页码
    "page_size": 20,     // 每页数量
    "items": []          // 数据列表
  }
}
```
