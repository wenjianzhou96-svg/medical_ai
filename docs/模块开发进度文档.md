#### 3.7 已知问题与解决方案
- **503 Service Unavailable**: 后端服务未启动或AI服务调用失败
  - 解决方案：确保后端服务已启动 (`uvicorn app.main:app --reload`)
  - 检查 MySQL、Redis 服务是否正常运行
  - 检查通义千问 API Key 是否有效
- **前端报错 Cannot read properties of undefined (reading 'length')**: 已通过防御性编程修复
  - 确保 messages 始终初始化为空数组
  - 增加 API 返回数据的数组类型检查
