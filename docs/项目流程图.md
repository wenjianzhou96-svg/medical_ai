### 1.2 AI智能问诊流程

```mermaid
sequenceDiagram
    participant U as 用户
    participant F as 前端
    participant API as API服务
    participant AI as AI服务
    participant KB as 知识库
    participant DB as 数据库
    participant Cache as 缓存
    
    U->>F: 进入问诊页面
    F->>API: POST /api/v1/consultations
    API->>DB: 创建问诊记录
    DB-->>API: 返回consultation_id
    API-->>F: 返回问诊ID
    F-->>U: 显示问诊界面
    
    U->>F: 输入症状描述
    F->>API: POST /api/v1/consultations/{id}/messages
    API->>Cache: 查询用户历史记录
    Cache-->>API: 返回历史记录
    API->>KB: 检索相关知识
    KB-->>API: 返回相关知识
    API->>AI: 调用LLM（包含上下文和知识）
    AI-->>API: 返回AI回复
    API->>DB: 保存对话记录
    DB-->>API: 保存成功
    API-->>F: 返回AI回复
    F-->>U: 显示AI回复
    
    loop 多轮对话
        U->>F: 回答AI追问
        F->>API: POST /api/v1/consultations/{id}/messages
        API->>AI: 继续对话
        AI-->>API: 返回回复
        API->>DB: 更新对话记录
        API-->>F: 返回回复
        F-->>U: 显示回复
    end
    
    AI->>API: 判断信息收集完整
    API->>AI: 生成诊断建议
    AI-->>API: 返回诊断建议
    API->>DB: 保存诊断建议
    API-->>F: 返回诊断建议
    F-->>U: 显示诊断建议
    
    opt 生成报告
        U->>F: 点击生成报告
        F->>API: POST /api/v1/consultations/{id}/report
        API->>AI: 生成报告内容
        AI-->>API: 返回报告
        API->>DB: 保存报告
        API-->>F: 返回报告URL
        F-->>U: 显示/下载报告
    end
```

### 1.5 医生审核问诊记录流程

sequenceDiagram

    participant API as API服务

    N-->>API: 通知发送成功

## 8. 流程图总结

1. **用户注册登录流程**：用户身份认证和授权
2. **AI智能问诊流程**：核心业务功能，多轮对话和知识检索
3. **健康数据分析流程**：数据查询、分析和可视化
4. **内容审核流程**：自动审核和人工审核结合
5. **医生审核流程**：医生审核AI建议

### 8.2 系统流程
