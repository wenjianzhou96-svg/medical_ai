# 数据库脚本说明

本目录包含医疗智能体系统的数据库建表脚本和模拟数据脚本。

## 文件说明

- `schema.sql` - 数据库建表脚本，包含所有表结构、索引和外键约束
- `mock_data.sql` - 模拟数据脚本，包含测试数据
- `README.md` - 本说明文件

## 使用方法

### 1. 创建数据库和表结构

```bash
# 使用MySQL命令行工具
mysql -u root -p < schema.sql

# 或者登录MySQL后执行
mysql -u root -p
source schema.sql;
```

### 2. 插入模拟数据

```bash
# 使用MySQL命令行工具
mysql -u root -p < mock_data.sql

# 或者登录MySQL后执行
mysql -u root -p
source mock_data.sql;
```

### 3. 一键执行（创建数据库+表+数据）

```bash
# 在项目根目录执行
mysql -u root -p < database/schema.sql
mysql -u root -p < database/mock_data.sql
```

## 数据库信息

> ⚠️ **注意**: schema.sql 中使用的数据库名为 `medical_ai`，与本文档描述的 `medical_agent_system` 一致。

- **数据库名**: `medical_ai`
- **字符集**: `utf8mb4`
- **排序规则**: `utf8mb4_unicode_ci`
- **存储引擎**: `InnoDB`

## 注意事项

1. **密码哈希**: 模拟数据中的密码哈希值仅为示例，实际使用时需要使用bcrypt等加密算法生成
2. **外键约束**: 建表脚本包含外键约束，确保数据完整性
3. **索引优化**: 已为常用查询字段建立索引，提高查询性能
4. **字符集**: 使用utf8mb4字符集，支持emoji等特殊字符

## 重置数据库

如果需要重置数据库，可以执行以下命令：

```sql
DROP DATABASE IF EXISTS medical_ai;
```

然后重新执行建表和数据插入脚本。

## 常见问题

### Q: 执行脚本时出现外键约束错误？
A: 确保按照正确的顺序执行脚本，先执行schema.sql创建表结构，再执行mock_data.sql插入数据。

### Q: 如何修改数据库名称？
A: 修改schema.sql文件开头的`CREATE DATABASE`语句中的数据库名称。

### Q: 如何清空所有数据但保留表结构？
A: 可以使用`TRUNCATE TABLE`命令清空各个表的数据，注意外键约束可能影响执行顺序。
